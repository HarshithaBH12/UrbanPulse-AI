# 🌆 UrbanPulse AI — City Digital Twin & Predictive Analytics

> An interactive data-science portfolio project for exploring urban signals, visualizing trends, and testing a simple traffic-pressure prediction model.

## ✨ Features

- **Live environmental signals:** current weather and European AQI are retrieved from the Open-Meteo APIs.
- **City overview:** dark dashboard, KPI cards, operational pulse chart, and traffic-pressure gauge.
- **Exploratory analytics:** inspect hourly sample data, select a signal, change the displayed time window, and export CSV.
- **Prediction lab:** adjust hour, day type, temperature, rainfall, AQI, and city activity to explore a Random Forest model's traffic-pressure index.
- **Model evaluation:** MAE, RMSE, R², and an actual-vs-predicted plot.
- **Multiple cities:** Bengaluru, Mumbai, Delhi, Hyderabad, Chennai, and Pune.

## ⚠️ Important data note

This is a **working portfolio prototype**, not an official city digital twin.

- Weather and European AQI are fetched live from Open-Meteo when the app loads.
- The historical traffic and energy records are **synthetic demonstration data** generated by the project.
- The traffic model is trained on that synthetic data. Its evaluation metrics demonstrate a model-evaluation workflow; they are **not evidence of real-world forecasting accuracy**.
- Traffic pressure is an index, not a travel-time estimate or a live traffic feed.
- If an API request fails, fallback values are shown and the app displays a warning.

A production version would need timestamped traffic, energy, and city operations feeds, data-quality checks, time-based validation, and monitoring for model drift.

## 🧰 Tech stack

Python · Pandas · NumPy · scikit-learn · Streamlit · Plotly · Open-Meteo API

**Power BI extension:** export the filtered dataset from *Explore Data* as CSV, then load that CSV into Power BI to build an additional report page. A `.pbix` file is not included in this repository.

## 🚀 Run locally in VS Code

### 1. Extract the project ZIP and open the folder

Open the `UrbanPulse_AI` folder in VS Code.

### 2. Create a virtual environment

**macOS / Linux**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

**Windows PowerShell**
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### 3. Install packages
```bash
pip install -r requirements.txt
```

### 4. Launch the dashboard
```bash
streamlit run app.py
```

Streamlit will print a local URL (usually `http://localhost:8501`) to open in your browser.

## 📊 Model approach

1. Generate reproducible hourly sample observations for each selected city.
2. Build features from hour, weekend, temperature, rainfall, AQI, and an event scenario.
3. Train a Random Forest Regressor to estimate the traffic-pressure index.
4. Evaluate on a holdout split using:
   - **MAE** — mean absolute error in index points
   - **RMSE** — root mean squared error in index points
   - **R²** — coefficient of determination
5. Let users vary scenario inputs and inspect how the model responds.
